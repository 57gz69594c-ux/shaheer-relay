### Step 1: Get a 1inch API key

Create/retrieve an API key for Swap API v6.1.

### Step 2: Set the environment variable

Add this ONE line to /etc/reaper/reaper.env:

  REAPER_ONEINCH_API_KEY=<your-1inch-api-key-here>

(Alternative accepted: REAPER_AGGREGATOR_API_KEY)

Optional — also helps if you have one:

  REAPER_ODOS_API_KEY=<from-https://dashboard.odos.xyz/>

### Step 3: Restart the engine

  sudo systemctl restart reaper-engine

That's it. The engine reads env vars from /etc/reaper/reaper.env at
startup. No code changes needed. No config file changes needed.
