1. CODE CHANGES COMPLETED (behavior verified via tests)
══════════════════════════════════════════════════════════════════════

A. ACQUISITION ACCOUNTING (4 buy functions)
   buy(), v3_buy(), v3_buy_spy(), v4_buy() now capture pre-buy
   balance snapshot and compute delta = post - pre. Entry price
   uses the actual acquired quantity, not total wallet balance.

B. SELL PROCEEDS ACCOUNTING (4 sell functions)
   sell(), v3_sell(), v3_sell_spy(), v4_sell() now capture pre-sell
   quote balance and compute received = post - pre. Returns
   attributed proceeds, not total wallet balance.

C. SELL MINIMUM OUTPUT — FRESH-QUOTE-BASED, REFUSE-TO-SIGN
   OLD: crude 50% of reference price floor, then retry at 30% (0.6x).
        Allowed 70% below reference. Zero fallback on unknown.
   NEW: minOut = fresh_quote x (1 - EXEC_SLIPPAGE_ALLOW/100).
        Primary attempt: 0.5% slip from quote.
        Retry: 1.0% slip from quote.
        No-quote fallback: REFUSE TO SIGN (return 0.0).
   Missing executable quotes cannot authorize signing or broadcasting
   a sale. The old (1, 'no-quote minimum') pattern authorized
   unprotected swaps — now replaced with refuse-to-sign.

D. ROUND-TRIP COST CHECK — TWO-TIER
   OLD: est_rt_cost = slip_pct x 2. Single 1.5% threshold.
   NEW: Impact estimate = slip_pct x 2.
        Expected check: impact <= 1.5% (MAX_RT_COST_EXPECTED).
        Bounded check: impact + 2 x EXEC_SLIPPAGE_ALLOW <= 2.5%
        (MAX_RT_COST_BOUNDED). Includes execution tolerance.

E. SLIPPAGE — ALL ROUTES
   check_slippage() now rejects when market_price <= 0 (was: PASS).
   SPY and V4-other routes now run slippage pre-check (were: skipped).

F. MOMENTUM VERIFICATION
   [100, 100, 19] now rejected: highest-to-last drop > 30%.
   B/S ratio re-checked at end of verification.

G. V4 HONEYPOT INCONCLUSIVE
   Unknown sell simulation reverts now return INCONCLUSIVE (block
   entry without blacklisting). Was: returned SAFE.

H. GAS RESERVATION
   SPY and V4-other routes now check eth_bal() < GAS_RESERVE.

I. ENTRY PREDICATE REAPPLICATION
   Final re-check of 5m%, B/S, MAX_5M_ENTRY, MOMENTUM_DEATH
   immediately before buy transaction.

J. COOLDOWN FILTERING
   Pre-filter cooldown/session-blocked/buy-failed/blacklisted
   tokens BEFORE ranking. Blocked token no longer blocks others.

K. SINGLE-INSTANCE ENFORCEMENT — OS FILE LOCK
   OLD: Read PID file, os.kill(pid, 0), kill or exit.
   NEW: fcntl.flock(LOCK_EX | LOCK_NB) on a lifetime-held lock file
        in /var/lib/rh-engine/{CID}-{wallet[:10]}/.
        Concurrent starts produce one owner. Newcomer refuses.
        Incumbent untouched. Lock released on process exit.

L. MONITOR RACE CONDITION
   Added _selling Event, mark_selling(), 10s join timeout,
   _sold flag, clear_sell_signal() after exits.

M. STATE PERSISTENCE — DURABLE DIRECTORY, ATOMIC WRITES
   OLD: /tmp/rh_engine_state.json (lost on reboot, non-atomic write)
   NEW: /var/lib/rh-engine/{CID}-{wallet[:10]}/ (stable, durable).
        Atomic write: mkstemp + os.replace (POSIX atomic).
        Blacklist migrated to same stable directory on init.
        _save_state() at all exit mutation points.

N. POSITION SIZING — 100% CEILING
   OLD: 5% of equity, capped at 0.15% of pool liquidity.
   NEW: Up to 100% of deployable capital (gas reserves, pending
        commitments, unmanaged holdings excluded). Actual-size
        execution, sellability, and economic checks constrain.
        NOTE: Near-full exposure can trigger the 3% daily circuit
        breaker after one approximately-3% losing position.

O. DAILY CIRCUIT BREAKER
   Pause new entries if equity drops >= 3% from UTC day-start equity.
   Includes ETH + SPY + USDG balance in equity calculation.
   UTC day rollover resets baseline. Once tripped, stays paused
   until new UTC day. Continue managing existing positions.

P. TAKE PROFIT — 100% EXIT AT +25%
   Per Shaheer directive: exit 100% of managed position at +25%.
   Policy B partial-profit runner DISABLED. No 50% retention.

Q. COOLDOWN — 60 SECONDS ON ALL EXITS
   60s cooldown after ALL completed position exits (winning AND
   losing). Policy C 180s alternative removed. EXIT_COOLDOWN.pop()
   for winners removed — cooldown is universal.

--- AMENDMENT 2 ADDITIONS (deep structural fixes) ---

R. _do_sell SENTINEL (-1 RETURN)
   OLD: returned fabricated 0.001 ETH when tokens gone, or used
        universal 100-token dust threshold as proceed certification.
   NEW: returns -1 sentinel when tokens gone but proceeds
        unattributed. All 3 callers (fast exit, latched exit, main
        exit) explicitly handle the sentinel: position resolved,
        cooldown applied, but proceeds NOT counted in totals.

S. EXIT PATH — NO BLOCKING BEFORE SELL SUBMISSION
   OLD: price_monitor.stop() called before _do_sell — joins worker
        thread for up to 10s, delaying protective sell submission.
   NEW: mark_selling() called before _do_sell instead.
        price_monitor.stop() NOT called until after sell completes.
        Fast exit and main exit paths both fixed.

T. SLIPPAGE QUOTE UNITS — TYPED AMOUNTS FOR V4/SPY
   OLD: check_slippage received ETH-equivalent for V4/SPY routes.
        For USDG (6 decimals): 0.024 ETH-equiv x 10^6 = 24000 raw
        = 0.024 USDG — 2500x too small for the quoter.
   NEW: check_slippage accepts quote_deploy + quote_dec parameters.
        enter() passes actual quote-token amounts for V4-other and
        SPY routes. V4 quoter receives correctly-scaled raw amounts.
   ALSO: Removed smaller-quote extrapolation. If V4 quoter reverts
        on full amount but succeeds at reduced size, REJECT (pool
        too thin). AMM slippage is nonlinear — extrapolation from
        partial quotes underestimates real impact.

U. SHADOW MODE
   New shadow() function and --shadow CLI option. Read-only: collects
   quotes, measures latency, logs decisions to shadow_log.jsonl.
   Does NOT sign, broadcast, approve, or change wallet state.
   Exercises production decision code without send_raw_transaction.

V. usdg_bal() + STATUS UPDATE
   New usdg_bal() function for USDG balance lookups (6 decimals).
   --status now displays USDG balance alongside ETH and SPY.

  3. If position open: manually manage exit before rollback
  4. cp scripts/rh_rotation_engine.py.v6.2.bak scripts/rh_rotation_engine.py

  6. Assess whether restart is safe given current wallet/position state

cooldowns that must survive across versions.
