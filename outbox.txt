AMENDMENT 3 CHANGES (on top of amendments 1 + 2):

Section 1 — Executable-Quote Cost Model:
  1. get_sell_quote() — actual V4/V3/V3spy quoter calls for managed
     quantity. Returns SellQuote with proceeds_usd, route, gas_estimate.
     Pons returns ok=False (no executable quote available).
  2. get_rt_cost_model() — actual buy→sell round-trip simulation.
     Replaced trivially equivalent 2×slip check with real quoter calls.
     Bounded RT cost adds EXEC_SLIPPAGE_ALLOW for both legs.
  3. Main loop PnL wired to executable quotes with 3-tier fallback:
     executable quote → stale cached executable → chart price.
  4. Trailing stop (EXIT 3) tracks exec_peak_usd from actual sell
     proceeds, not chart-price peak.
  5. Removed automatic 1% retry widening from ALL 4 sell functions
     (Pons, V3-WETH, V3-SPY, V4). Single attempt at EXEC_SLIPPAGE_ALLOW,
     caller retries next tick with fresh quote.

Section 2 — Managed Inventory & TradeOutcome:
  6. TradeOutcome class replaces numeric -1 sentinel. States:
     RESOLVED, UNRESOLVED, FAILED, PENDING. Carries proceeds_usd,
     cost_basis_usd, managed_raw, route, token_addr, tx_hash.
  7. _do_sell returns TradeOutcome for all paths:
     - result > 0 → TradeOutcome.RESOLVED with proceeds
     - tokens gone but 0 proceeds → TradeOutcome.UNRESOLVED
     - tokens still held → TradeOutcome.FAILED
  8. ALL callers updated: fast exit, latched exit, main exit, bad-fill
     sell-back. Old `e == -1` → `outcome.is_unresolved`, old `e > 0` →
     `outcome.is_resolved`.
  9. Loss counting uses attributed net outcome (proceeds - cost_basis),
     not chart PnL. Unresolved trades do NOT count as wins or losses.
  10. All 4 sell functions (sell, v3_sell, v3_sell_spy, v4_sell) accept
      managed_raw parameter. Sell exact acquired quantity, not full balance.
  11. _do_sell passes managed_raw through to underlying sell functions.

Section 4 — Durable State & Portfolio Controls:

      Migration: copytree from old truncated dir if new dir absent.
  13. Persist UTC day, equity baseline, entry_paused across restart via
      _save_state/_load_state (day_start_equity + entry_paused fields).
  14. Loss timestamps (24h expiry) already persisted in state file.

Section 5 — Read-Only Verification:
