7. BUGS FOUND & FIXED IN v6.2
===============================

BUG 1: DUAL ENGINE INSTANCES
  Two Claude sessions each started the engine independently.
  Both traded the same wallet simultaneously causing nonce collisions
  and duplicate buys (UNITY bought twice at different prices).
  FIX: PID lockfile at /tmp/rh_engine.pid — new instance kills old one.

BUG 2: STOP-LOSS OVERSHOOT (-35% on -3% SL)
  Pool discovery (_discover_pool) ran AFTER buying and blocked the
  thread for up to 30 seconds. Price crashed during this gap.
  By the time monitoring started, loss was already -35%.
  FIX: Pool discovery moved to BEFORE buy. Monitor starts immediately.

BUG 3: V4 UNPROTECTED BUYS (minOut=0)
  When V4 quoter failed, engine fell back to minOut=0 allowing
  unlimited adverse execution. Bad fills of -20% to -46% resulted.
  FIX: Quote failure now REJECTS the buy entirely.

BUG 4: READINGS VARIABLE UNDEFINED
  After removing momentum verification, the code still referenced
  the `readings` variable in position creation. Would crash on
  next trade attempt.
  FIX: Momentum verification restored (3 readings, 6s, no extra delay).

BUG 5: ACCOUNTING ERRORS
  Fill calculation used entire wallet token balance, not purchase delta.
  Sell logging used entire quote-token balance, not sale proceeds.
  Identified by Codex Ultra — acknowledged, monitoring for impact.
