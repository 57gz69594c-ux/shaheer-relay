AMENDMENT 6 CHANGES (responding to docking station note-1788874993552):

Section 1 — Concrete Bug Fixes (from ChatGPT review):
  1. SellQuote gas_estimate: removed from base dict, each constructor
     provides it explicitly. No duplicate keyword argument.
  2. _acquire_nonce now registers durable TxOp BEFORE returning nonce.
     Returns (nonce, op) tuple. _nonce_only wraps for backward compat.
  3. resync_nonce: takes max(chain_nonce, max_pending_nonce + 1) —
     never reissues a nonce with pending operations.
  4. Reverted receipts: already handled correctly (status != 1 check).
  5. _do_sell fail-closed: when bal() throws after positive proceeds,
     returns UNRESOLVED, not RESOLVED. Cannot certify sale without
     balance verification.
  6. Duplicate receipts: PositionLedger.record_sell is idempotent on
     tx_hash — same hash cannot credit proceeds twice.
  7. AttributeDict serialization: TxOp.to_dict and PositionLedger.to_dict
     normalize Web3 AttributeDict → plain dict.

Section 2 — Transaction Coordination (broadcast + timeout):
  8. TxOp: added TIMEOUT status, broadcast_attempted_at, signed_hash.
     Distinguishes "tx may still confirm" from "no tx hash obtained".
  9. TxCoordinator: added mark_broadcast(), mark_timeout(),
     reconcile_op(), has_unreconciled(), timeout_ops().
  10. _broadcast() helper: records transport attempt durably BEFORE
      calling send_raw_transaction. Persists state for crash safety.
      Records tx_hash in op after successful send.
  11. _wait_receipt() helper: on timeout marks op as TIMEOUT (not
      FAILED). Returns None on timeout so caller can retry/reconcile.
      On success calls confirm_op with receipt.

Section 3 — Zero-Reset Approvals:
  12. approve(): if allowance is nonzero but < 10^30, calls approve(0)
      before approve(MAX). Required by USDT-like tokens.
  13. _ensure_permit2_approval(): if ERC20→Permit2 allowance is nonzero
      but insufficient, calls approve(permit2, 0) first.

Section 4 — Portfolio Equity Without Double-Counting:
  14. _portfolio_equity(): includes native ETH + WETH + SPY + USDG +
      managed position value. Subtracts proceeds already in ETH to
      prevent double-counting partial proceeds.
  15. _check_daily_drawdown(): now uses _portfolio_equity() instead of
      eth_bal() * ETH_USD + spy_bal_usd() + usdg_bal().
