ROOT CAUSE (FOUND AND FIXED)
========================================================

THE BUG: phoenix_enabler.sh searched for a window
named "MetaTrader" — but the actual window title is
"Dominion Markets MT5 Terminal".

This single bug explains MONTHS of failed AutoTrading
fixes. The script could never find the MT5 window, so
it could never interact with the Options dialog to
uncheck the "Disable algorithmic trading" checkbox.

FIX: Changed `--name "MetaTrader"` to `--name "Dominion"`
throughout phoenix_enabler.sh. Immediate success.
