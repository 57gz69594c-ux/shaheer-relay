1. SOFTWARE DEFECTS FIXED (14 confirmed)
══════════════════════════════════════════════════════════════════════

A. ACQUISITION ACCOUNTING (4 buy functions)
   DEFECT: buy(), v3_buy(), v3_buy_spy(), v4_buy() all used
           bal(token_addr) — the TOTAL wallet balance — as acquired
           quantity. A wallet holding 1000 tokens that buys 1000 more
           would record 2000 acquired at $0.05 instead of 1000 at $0.10.
   FIX: All 4 functions now capture pre-buy balance snapshot and compute
        delta = post_balance - pre_balance. Entry price = cost / delta.

B. SELL PROCEEDS ACCOUNTING (4 sell functions)
   DEFECT: sell(), v3_sell(), v3_sell_spy(), v4_sell() returned the
           entire quote-token wallet balance as sale proceeds.
   FIX: All 4 functions now capture pre-sell quote balance and compute
        received = post_balance - pre_balance.

C. ZERO-MINIMUM-OUTPUT EXIT FALLBACK
   DEFECT: All 4 sell functions retried with amountOutMinimum=0 on revert.
           This exposes the position to unlimited slippage (sandwich attacks).
   FIX: Replaced (0, 'EMERGENCY min_out=0') with (int(min_out * 0.6),
        '30% floor retry') in all 4 sell functions.

D. SLIPPAGE CHECK — ZERO PRICE
   DEFECT: check_slippage() returned (True, 0.0) when market_price <= 0,
           treating unknown slippage as PASS.
   FIX: Now returns (False, 100.0) — rejects with 100% assumed slippage.

E. SLIPPAGE CHECK — SPY AND V4-OTHER ROUTES
   DEFECT: Slippage pre-check was skipped entirely for SPY-paired and
           V4-other (USDG/HIMS/NVDA) routes.
   FIX: All routes now run slippage check, converting deploy amounts
        to ETH-equivalent for comparison.

F. MOMENTUM VERIFICATION
   DEFECT: [100, 100, 19] passed because decline check required strict
           monotonic readings[2] < readings[1] < readings[0].
   FIX: Now computes highest-to-last drop: if drop > 30%, reject.
        Also re-checks B/S ratio at end of verification.

G. V4 HONEYPOT INCONCLUSIVE
   DEFECT: Universal Router sell simulation that reverted with unknown
           error returned True (SAFE).
   FIX: Inconclusive results now return False (block entry without
        blacklisting). Same fix for transfer simulation.

H. GAS RESERVATION
   DEFECT: SPY and V4-other routes did not check ETH balance for gas.
   FIX: Added eth_bal() < GAS_RESERVE check for both routes.

I. ENTRY PREDICATE REAPPLICATION
   DEFECT: 2-15 seconds between momentum verification and buy call.
           Conditions never re-checked.
   FIX: Final re-check of 5m%, B/S ratio, MAX_5M_ENTRY, MOMENTUM_DEATH
        right before buy transaction executes.

J. COOLDOWN FILTERING
   DEFECT: scan() returned only 1 candidate. If it was on cooldown,
           enter() returned None instead of trying 2nd-best.
   FIX: Pre-filter cooldown, session-blocked, buy-failed, and blacklisted
        tokens BEFORE ranking/pick logic.

K. PID ENFORCEMENT
   DEFECT: New engine instance killed the incumbent process.
   FIX: Newcomer calls sys.exit(1) if incumbent is alive.

L. MONITOR RACE CONDITION
   DEFECT: PriceMonitor thread join timeout of 2s allowed stale thread
           to survive and fire sell signals against a new position.
   FIX: Added _selling threading.Event, mark_selling() method, increased
        join timeout to 10s, added _sold position flag.

M. STATE PERSISTENCE
   DEFECT: Cooldowns, losses, buy fail counts were only in-memory.
           Restart erased all loss history.
   FIX: Added _load_state()/_save_state() with /tmp/rh_engine_state.json.
        _save_state() called at ALL exit mutation points (7 locations).

N. ROUND-TRIP COST CHECK
   DEFECT: No pre-buy check for whether the position could break even
           after round-trip execution costs.
   FIX: Estimates RT cost as slippage × 2. Rejects if > 1.5%.
