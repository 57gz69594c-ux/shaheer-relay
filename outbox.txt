WHAT IT IS:
A fully autonomous Solana memecoin trading engine that discovers new tokens,
scores them with a trained ML model, executes trades on-chain, and manages
positions 24/7 with no human intervention.

==============================================================================
1. DISCOVERY LAYER — Finding New Tokens
==============================================================================

File: src/engine_a/discovery.py

- Pulls trending + new tokens from CoinGecko API every scan cycle
- Sources: /coins/markets, /search/trending, /coins/list (new listings)
- Filters: Solana-only, minimum liquidity, excludes stablecoins/wrapped
- Deduplicates against already-seen tokens in decision_log.db
- Output: List of candidate token IDs ready for feature extraction

Rate limits: Handles 429s with exponential backoff (CoinGecko free tier)

==============================================================================
2. FEATURE EXTRACTION — Building the Signal
==============================================================================

File: src/engine_a/feature_extractor.py

Pulls raw market data from CoinGecko for each candidate and computes:

  Core features (7 per tier):
  - fdv_tvl_ratio: Fully diluted valuation / Total value locked
  - log_fdv: Log10 of FDV (size signal)
  - btc_30d_return: Bitcoin's 30-day return (market regime proxy)
  - tge_type_score: Token generation event type (fair launch=0.8, ICO=0.3)
  - is_memecoin, is_gaming_nft, is_defi: Category flags
  - initial_float_pct: Circulating supply percentage
  - investor_tier_score: Backer quality (tier1=1.0, unknown=0.5)
  - is_binance_launchpool: Binance listing flag
  - is_bull_regime: 1 if BTC 30d > +5%
  - is_solana: Chain flag
  - memecoin_x_bull: Interaction term (memecoin in bull market)

  Shadow/Phantom v2 features (for merged engine validation):
  - drawdown_from_peak, vol_acceleration, volume_concentration
  - buy_pressure_ratio, vwap_deviation
  - liquidity_mcap_ratio, holder_growth_rate

==============================================================================
3. PUMP CLASSIFIER — The Brain (ML Model)
==============================================================================

File: src/engine_a/pump_classifier.py
Model files: models/pump_model_v7b_*.pkl (13 files)

THREE independent logistic regression models running in parallel:

  2x Model: "Will this token 2x within 30 days?"
  - Features: fdv_tvl_ratio, log_fdv, btc_30d_return, tge_type_score,
              is_memecoin, is_gaming_nft, is_defi
  - Threshold: 28% probability -> alert
  - Regularization: C=5.0
  - Walk-forward backtest: 43.6% precision, +$12,278 PnL

  5x Model: "Will this token 5x within 30 days?"
  - Features: initial_float_pct, investor_tier_score, btc_30d_return,
              is_binance_launchpool, tge_type_score, is_l2, is_l1
  - Threshold: 15% -> alert
  - Walk-forward backtest: 29% precision, +$31,106 PnL

  10x Model: "Will this token 10x within 30 days?"
  - Features: is_bull_regime, is_memecoin, is_gaming_nft, is_solana,
              memecoin_x_bull
  - Threshold: 10% -> alert
  - Walk-forward backtest: 35% precision, +$63,147 PnL

Trained on: 299 real token outcomes (MFE_30d = max favorable excursion)
Validation: Monthly expanding-window walk-forward on 258 tokens (2020-2025)

KEY INSIGHT: The btc_30d_return feature already handles bull/bear markets.
No separate market gate needed — model self-adjusts. Proven by backtest:
BEAR months had equal/higher precision than BULL months.

==============================================================================
4. LIVE RANKER — Breaking Ties
==============================================================================

File: src/engine_a/live_ranker.py

When multiple tokens pass the pump classifier threshold, the live ranker
picks the BEST one using real-time signals:

  - Market cap rank (smaller = higher upside potential)
  - Volume/MCap ratio (high = momentum building)
  - Price momentum (short-term trend direction)
  - ATH distance (how far below all-time high)
  - Rug detection (honeypot/scam flags -> instant disqualify)

Output: Single best token recommendation for the strategist

==============================================================================
5. SCANNER — The Orchestrator
==============================================================================

File: scripts/engine_a_scanner.py
Timer: engine-a-scanner.timer (runs every 6 hours)

The scanner ties everything together in one pipeline:

  Discovery -> Feature Extraction -> Pump Classifier -> Live Ranker -> Alert

Steps per cycle:
  1. Call discovery.py to find new Solana tokens from CoinGecko
  2. For each candidate, extract features via feature_extractor.py
  3. Run all three pump classifier models (2x, 5x, 10x)
  4. If any model fires above threshold, pass to live_ranker.py
  5. Log decision in decision_log.db
  6. If alert-worthy, notify via alert_notifier.py
  7. Pass top pick to strategist for trade execution

No whale filter (dormant) — 1h whale snapshots don't help 30-day holds.

6. DECISION LOG — Audit Trail
==============================================================================

File: src/engine_a/decision_log.py
Database: data/decision_log.db

Every scanner decision is permanently recorded:

Purpose: Full auditability. Can replay any past decision and understand why.

8. STRATEGIST — Trade Decision Engine (Layer 2)
==============================================================================

File: src/engine_a/strategist.py
Timer: engine-a-trader.timer (runs every 2 hours)

The strategist makes the actual BUY/SELL/HOLD/ROTATE decisions:

  Core logic:
  - Maintains a paper portfolio (and live portfolio via Phantom wallet)
  - Compares current holding vs. new scanner recommendations
  - Calculates composite_delta = new_score - current_score
  - If delta > MIN_COMPOSITE_DELTA (0.15), triggers rotation

  Position sizing (after fix):
  - Deploys FULL wallet balance minus 0.05 SOL fee reserve
  - No cap — previously had 2.0 SOL cap that left money idle
  - Example: 4.5 SOL balance -> deploys 4.45 SOL

  Codex Ultra integration:
  - BUY-FIRST-VALIDATE-AFTER pattern:
    1. Execute the swap immediately for best entry price
    2. Submit trade rationale to Codex Ultra for review
    3. If Codex Ultra rejects: auto-exit (worst case: 2.5% swap cost)
    4. If Codex Ultra approves: hold position
  - Codex Ultra prompts kept under 50 words (speed requirement)
  - Codex worker runs at localhost:8872 with shared lease scheduler

  Key parameters (Codex Ultra tuned):
  - SWAP_COST_PCT = 1.0% (Solana DEX slippage estimate)
  - MIN_COMPOSITE_DELTA = 0.15 (minimum score improvement to rotate)
  - MIN_HOLD_MINUTES = 90 (prevent churning)
  - REPURCHASE_COOLDOWN_H = 6 (don't re-buy recently sold tokens)

  Exit conditions:
  - TIMEOUT_UNDERPERFORM: 6h hold with < target return -> exit
  - STOP_LOSS: -15% from entry -> immediate exit
  - ROTATION: Better token found with delta > 0.15 -> swap
  - CODEX_REJECT: Codex Ultra vetoes post-buy -> exit

9. SENTINEL — Price Watchdog (Layer 1)
==============================================================================

File: src/engine_a/sentinel.py
Timer: engine-a-settle.timer (runs every 12 hours for settlement)
Active: ~1-minute price check loop (was 5-min)

The sentinel is the fast-reaction safety layer:

  Monitors:
  - Current price vs. entry price (P&L tracking)
  - Rapid price movements (pump/dump detection)
  - Price snapshots stored in data/sentinel.db

  Thresholds:
  - RAPID_PUMP: +15% in one cycle -> consider taking profit
  - RAPID_DUMP: -10% in one cycle -> alert/prepare exit
  - EMERGENCY_DUMP: -20% in one cycle -> immediate exit

  Works independently from the strategist. Sentinel can force-exit a
  position even if the strategist says HOLD — safety override.
