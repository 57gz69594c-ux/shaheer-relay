=== ACTION REQUIRED: Install Your Helius API Key ===

Everything is built and waiting. You just need to run ONE command on the server.

STEP 1: Get a free Helius API key
  Go to https://www.helius.dev
  Sign up (free tier is fine — no credit card needed)
  Copy your API key from the dashboard

STEP 2: SSH into your server and run this single command:
  sudo /usr/local/sbin/ascension-set-helius-key

  It will prompt you: "Enter Helius API key:"
  Paste your key and press Enter.
  (The key is hidden — nothing will appear on screen as you paste. That's normal.)

STEP 3: Start the collector:
  sudo systemctl start ascension-event-genesis

STEP 4: Verify it's running:
  ascension-collector-status

That's it. The 24-hour certification begins automatically.

DO NOT paste your key into Claude, GitHub, or any chat.
DO NOT pass it as a command-line argument.
The installer reads it silently and stores it securely.
