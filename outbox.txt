## WHAT IS THE REAPER DRONE?

A fully automated DeFi liquidation bot system. It monitors lending protocols (Aave, SparkLend, Venus, Moonwell, Compound, etc.) for borrowers whose Health Factor drops below 1.0, then flash-liquidates them to collect the liquidation bonus (typically 5-10% of the debt repaid).

The system uses flash loans (borrow, liquidate, repay in one atomic transaction, zero capital needed) via custom-deployed FlashLiquidator smart contracts.

2. reaper-sniper.service (mempool_sniper.py v2 — 2,076 lines)
Three operating modes:
- MEMPOOL MODE (ETH, Polygon, BNB): Subscribes to Alchemy pendingTransactions filtered to Chainlink oracle aggregator addresses. Sees oracle price updates BEFORE they are mined into a block. - L2 FAST MODE (Arbitrum, Base, Avalanche): Subscribes to newHeads (new blocks), instantly looks up precomputed price table for that block's price changes.
- BLOCK MODE (fallback): For chains without websocket support.

3. reaper-deep-scan.service (deep_scanner.py)
- One-shot full scan of all borrowers on all protocols/chains
- Populates the state JSON files that fleet_monitor uses
- Completed 20/22 scan tasks successfully
